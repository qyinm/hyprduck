Built for file-to-markdown workflows

Parse existing files into structured markdown instead of rebuilding them by hand.

File Parsing

Import PDFs and Word documents, then convert every page into a parseable image snapshot for reliable multimodal extraction.

  • PDF, DOCX, and DOC support
  • Per-page conversion pipeline
  • No screen permissions required

Provider-Based AI

Choose OpenRouter, OpenAI, Anthropic, or Ollama depending on your latency, privacy, and cost needs.

  • Shared provider settings
  • Preset and custom model IDs
  • Prompt templates for different document shapes

Markdown Packages

Export clean markdown plus the page images it references, so the result stays inspectable and easy to move into any downstream tool.

  • Linked image assets
  • Partial-save and retry support
  • Ready for docs, wikis, and notes
